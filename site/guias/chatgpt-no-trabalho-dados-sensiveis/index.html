Como usar ChatGPT no trabalho sem expor dados sensíveis

Resposta curta

No trabalho, ferramentas como ChatGPT devem ser usadas com dados minimizados, sem informação pessoal desnecessária, sem contratos completos de clientes e sem segredos comerciais. A regra prática é simples: se não podia ir num email externo sem autorização, também não deve entrar num prompt.

O que não deve entrar num prompt

  • Dados pessoais identificáveis de clientes ou trabalhadores.
  • Contratos completos, propostas confidenciais e passwords.
  • Código proprietário sensível sem autorização.
  • Informação financeira não pública.
  • Dados de saúde, jurídicos ou de menores.

Usos seguros para começar

UsoComo reduzir risco
Rever textoRemover nomes, emails e valores específicos
Gerar estruturaUsar contexto abstrato em vez de documentos reais
Resumir documentoUsar versões anonimizadas ou ferramentas empresariais aprovadas

Política mínima para equipas

Uma empresa não precisa de um manual de 40 páginas para começar. Precisa de três linhas claras: que ferramentas são permitidas, que dados são proibidos e quem aprova exceções.

Ângulo PTIA

A produtividade prometida pela IA só compensa se não criar uma fuga silenciosa de informação. O uso maduro não é bloquear tudo. É definir fronteiras simples que permitam trabalhar sem transformar cada prompt num risco.
