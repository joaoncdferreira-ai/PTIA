Agente de IA

AI agent
4 menções PTIA · 12 semanas

Sistema que usa um modelo de IA para escolher e executar passos, utilizar ferramentas e verificar resultados com algum grau de autonomia.

Exemplo: Um agente pode consultar uma base de dados, preparar um relatório e pedir aprovação antes de o enviar.

Relacionados: LLM · tool use · workflow

AGI

Artificial General Intelligence
6 menções PTIA · 12 semanas

Conceito de uma inteligência artificial geral capaz de realizar uma grande variedade de tarefas cognitivas, sem ficar limitada a um domínio estreito.

Exemplo: AGI é uma hipótese e um objetivo de investigação, não uma capacidade com definição ou teste universalmente aceite.

Relacionados: IA · modelo de fronteira

AI Act

Artificial Intelligence Act
1 menções PTIA · 12 semanas

Regulamento da União Europeia que estabelece obrigações para sistemas de IA de acordo com o risco, o papel de cada interveniente e o tipo de utilização.

Exemplo: Um sistema usado em recrutamento pode estar sujeito a requisitos mais exigentes do que um filtro de spam.

Relacionados: sistema de alto risco · GPAI · governação

Alinhamento

Alignment
4 menções PTIA · 12 semanas

Área que procura fazer com que o comportamento de um sistema de IA corresponda às intenções, regras e valores definidos pelos seus operadores e pela sociedade.

Exemplo: Um modelo alinhado deve recusar ações perigosas mesmo quando a instrução parece tecnicamente executável.

Relacionados: segurança de IA · RLHF

Alucinação

Hallucination
0 menções PTIA · 12 semanas

Resposta gerada com informação falsa, inventada ou sem suporte, apresentada de forma plausível.

Exemplo: Um modelo pode criar uma referência académica que não existe.

Relacionados: grounding · RAG · verificação

API

Application Programming Interface
17 menções PTIA · 12 semanas

Interface que permite a um programa pedir dados ou ações a outro sistema de forma estruturada.

Exemplo: Uma aplicação pode usar uma API para enviar texto a um modelo e receber uma resposta.

Relacionados: integração · tool use

Aprendizagem automática

Machine learning
0 menções PTIA · 12 semanas

Conjunto de técnicas em que sistemas aprendem padrões a partir de dados para fazer previsões, classificações ou gerar conteúdo.

Exemplo: Um modelo pode aprender a identificar fraude a partir de transações históricas.

Relacionados: deep learning · modelo

Base de dados vetorial

Vector database
0 menções PTIA · 12 semanas

Sistema otimizado para guardar embeddings e encontrar itens semanticamente semelhantes.

Exemplo: Uma base vetorial pode recuperar os documentos mais próximos de uma pergunta.

Relacionados: embeddings · RAG

Benchmark

4 menções PTIA · 12 semanas

Teste ou conjunto de tarefas usado para comparar o desempenho de modelos ou sistemas.

Exemplo: Um benchmark pode medir qualidade em programação, matemática ou compreensão de texto.

Relacionados: avaliação · modelo

Cadeia de raciocínio

Chain of thought
0 menções PTIA · 12 semanas

Sequência intermédia de passos usada por um modelo para chegar a uma resposta; nem sempre é visível nem deve ser confundida com uma explicação verificável.

Exemplo: Pedir uma justificação concisa e factos verificáveis é mais útil do que assumir que texto intermédio prova o raciocínio real.

Relacionados: modelo de raciocínio · prompt

Deep learning

0 menções PTIA · 12 semanas

Subárea da aprendizagem automática baseada em redes neuronais com múltiplas camadas.

Exemplo: Reconhecimento de imagem e grandes modelos de linguagem usam técnicas de deep learning.

Relacionados: rede neuronal · transformer

Deepfake

0 menções PTIA · 12 semanas

Conteúdo audiovisual sintético ou manipulado para imitar de forma convincente uma pessoa, voz ou acontecimento.

Exemplo: Um vídeo pode aparentar mostrar alguém a dizer algo que nunca disse.

Relacionados: IA generativa · proveniência

Destilação

Distillation
0 menções PTIA · 12 semanas

Técnica para treinar um modelo mais pequeno a reproduzir parte do comportamento de um modelo maior.

Exemplo: Uma empresa pode destilar um modelo para reduzir custo e latência numa tarefa específica.

Relacionados: SLM · modelo

Embeddings

0 menções PTIA · 12 semanas

Representações numéricas de texto, imagem ou outros dados que preservam relações de significado e permitem comparar proximidade semântica.

Exemplo: Embeddings permitem encontrar documentos relacionados mesmo quando não usam as mesmas palavras.

Relacionados: base vetorial · RAG

Few-shot

0 menções PTIA · 12 semanas

Técnica de prompting em que são fornecidos alguns exemplos para mostrar ao modelo o padrão esperado.

Exemplo: Dois exemplos de classificação podem orientar o formato das respostas seguintes.

Relacionados: prompt · zero-shot

Fine-tuning

0 menções PTIA · 12 semanas

Treino adicional de um modelo pré-existente com dados direcionados para adaptar comportamento ou desempenho.

Exemplo: Um modelo pode ser afinado para classificar documentos de um setor específico.

Relacionados: modelo de fundação · dados de treino

GPAI

General-Purpose Artificial Intelligence
0 menções PTIA · 12 semanas

Modelo de IA de finalidade geral, designação usada no AI Act para modelos capazes de servir múltiplos objetivos e integrações.

Exemplo: Um modelo generalista fornecido por API pode ser integrado em muitas aplicações diferentes.

Relacionados: AI Act · modelo de fundação

Grounding

0 menções PTIA · 12 semanas

Ligação da resposta de um modelo a dados, documentos ou ferramentas concretas para reduzir invenções e aumentar verificabilidade.

Exemplo: Um assistente responde com base no manual interno e mostra a secção usada.

Relacionados: RAG · alucinação

Guardrails

0 menções PTIA · 12 semanas

Regras e controlos técnicos que limitam entradas, ações ou saídas de um sistema de IA.

Exemplo: Um guardrail pode bloquear a exposição de dados pessoais ou exigir aprovação humana.

Relacionados: segurança · governação

IA generativa

Generative AI
2 menções PTIA · 12 semanas

Sistemas de IA capazes de criar texto, imagem, áudio, vídeo, código ou outros conteúdos.

Exemplo: Um modelo pode gerar um primeiro rascunho de uma apresentação a partir de um brief.

Relacionados: LLM · difusão

Inferência

Inference
0 menções PTIA · 12 semanas

Momento em que um modelo já treinado processa uma entrada para produzir uma previsão ou resposta.

Exemplo: Cada resposta de um chatbot implica uma execução de inferência.

Relacionados: treino · latência

Janela de contexto

Context window
0 menções PTIA · 12 semanas

Quantidade máxima de informação que um modelo consegue considerar numa interação, medida normalmente em tokens.

Exemplo: Documentos muito extensos podem ultrapassar a janela e exigir seleção ou divisão.

Relacionados: token · LLM

LLM

Large Language Model
0 menções PTIA · 12 semanas

Grande modelo de linguagem treinado para prever e gerar sequências de texto, podendo também trabalhar com código, imagens ou ferramentas.

Exemplo: Um LLM pode resumir um contrato, mas o resultado deve ser revisto.

Relacionados: transformer · token · modelo de fundação

MCP

Model Context Protocol
0 menções PTIA · 12 semanas

Protocolo aberto para ligar aplicações de IA a ferramentas, dados e serviços através de uma interface comum.

Exemplo: Um cliente de IA pode usar MCP para consultar um repositório ou uma base de dados autorizada.

Relacionados: agente de IA · tool use · API

Modelo de fronteira

Frontier model
0 menções PTIA · 12 semanas

Expressão usada para modelos entre os mais capazes do momento, normalmente com elevado custo, escala e potencial de risco.

Exemplo: A definição exata depende do contexto técnico ou regulatório.

Relacionados: GPAI · segurança de IA

Modelo de fundação

Foundation model
0 menções PTIA · 12 semanas

Modelo treinado em grandes volumes de dados que pode ser adaptado a muitas tarefas posteriores.

Exemplo: Um LLM generalista pode servir de base a assistentes, classificadores e agentes.

Relacionados: LLM · fine-tuning

Modelo de raciocínio

Reasoning model
0 menções PTIA · 12 semanas

Modelo otimizado para dedicar mais computação a problemas com vários passos, como programação, matemática ou planeamento.

Exemplo: Pode ser mais eficaz em tarefas complexas, mas também mais lento e caro.

Relacionados: inferência · cadeia de raciocínio

Modelo multimodal

Multimodal model
0 menções PTIA · 12 semanas

Modelo capaz de processar ou gerar mais do que um tipo de informação, como texto, imagem, áudio ou vídeo.

Exemplo: Um modelo multimodal pode analisar uma fotografia e responder a perguntas sobre ela.

Relacionados: LLM · visão computacional

NLP

Natural Language Processing
0 menções PTIA · 12 semanas

Processamento de linguagem natural: área dedicada a fazer computadores analisar, compreender ou gerar linguagem humana.

Exemplo: Classificação de texto, tradução e pesquisa semântica são tarefas de NLP.

Relacionados: LLM · embeddings

Open weights

0 menções PTIA · 12 semanas

Modelo cujos pesos treinados são disponibilizados para utilização ou adaptação, sob uma licença que pode manter restrições.

Exemplo: Open weights não significa necessariamente código aberto nem liberdade total de uso.

Relacionados: modelo · licença

Parâmetros

Parameters
0 menções PTIA · 12 semanas

Valores internos aprendidos durante o treino que influenciam como o modelo transforma entradas em resultados.

Exemplo: O número de parâmetros é um indicador de escala, não uma medida suficiente de qualidade.

Relacionados: treino · modelo

Prompt

0 menções PTIA · 12 semanas

Instrução, contexto ou conjunto de exemplos fornecido a um modelo para orientar a resposta.

Exemplo: Um bom prompt define objetivo, contexto, restrições e formato esperado.

Relacionados: few-shot · zero-shot

Prompt injection

0 menções PTIA · 12 semanas

Ataque ou manipulação em que instruções maliciosas tentam desviar um sistema de IA das suas regras ou fazê-lo revelar informação.

Exemplo: Texto escondido num documento pode tentar ordenar ao agente que ignore a política de segurança.

Relacionados: segurança · agente de IA · guardrails

Quantização

Quantization
0 menções PTIA · 12 semanas

Redução da precisão numérica dos pesos ou cálculos de um modelo para diminuir memória, custo e latência.

Exemplo: Um modelo quantizado pode correr num portátil com alguma perda de qualidade.

Relacionados: inferência · SLM

RAG

Retrieval-Augmented Generation
11 menções PTIA · 12 semanas

Arquitetura que recupera informação relevante antes de gerar uma resposta, permitindo usar fontes externas ou privadas.

Exemplo: Um chatbot interno procura documentos da empresa e responde com referências.

Relacionados: embeddings · base vetorial · grounding

Rede neuronal

Neural network
0 menções PTIA · 12 semanas

Modelo computacional composto por camadas de unidades ligadas que aprendem padrões através do ajuste de parâmetros.

Exemplo: Redes neuronais são usadas em visão, fala e linguagem.

Relacionados: deep learning · transformer

RLHF

Reinforcement Learning from Human Feedback
0 menções PTIA · 12 semanas

Treino por reforço com feedback humano, técnica usada para ajustar modelos segundo preferências avaliadas por pessoas.

Exemplo: Avaliadores comparam respostas para ajudar o modelo a produzir resultados mais úteis.

Relacionados: alinhamento · fine-tuning

Sistema de alto risco

High-risk AI system
0 menções PTIA · 12 semanas

Categoria do AI Act para certas utilizações de IA com potencial significativo de afetar segurança ou direitos fundamentais.

Exemplo: Algumas utilizações em emprego, educação ou serviços essenciais podem entrar nesta categoria.

Relacionados: AI Act · avaliação de risco

SLM

Small Language Model
0 menções PTIA · 12 semanas

Modelo de linguagem pequeno, concebido para menor custo, latência ou execução local face a modelos de grande escala.

Exemplo: Um SLM pode ser suficiente para classificar pedidos num dispositivo.

Relacionados: LLM · destilação · quantização

Temperatura

Temperature
0 menções PTIA · 12 semanas

Parâmetro que influencia a variabilidade das respostas geradas por alguns modelos.

Exemplo: Temperatura mais baixa tende a produzir respostas mais previsíveis, sem garantir exatidão.

Relacionados: inferência · prompt

Token

0 menções PTIA · 12 semanas

Unidade em que um modelo divide texto ou outros dados para os processar; uma palavra pode corresponder a um ou mais tokens.

Exemplo: Custos e limites de contexto são frequentemente calculados em tokens.

Relacionados: janela de contexto · LLM

Tool use

0 menções PTIA · 12 semanas

Capacidade de um modelo chamar funções ou serviços externos para obter dados ou executar ações.

Exemplo: Um assistente pode consultar o calendário através de uma ferramenta autorizada.

Relacionados: agente de IA · API · MCP

Transformer

0 menções PTIA · 12 semanas

Arquitetura de rede neuronal baseada em mecanismos de atenção, usada em muitos modelos modernos de linguagem e multimodais.

Exemplo: A arquitetura transformer permite relacionar elementos distantes numa sequência.

Relacionados: LLM · atenção

Visão computacional

Computer vision
0 menções PTIA · 12 semanas

Área da IA dedicada à análise e compreensão automática de imagens e vídeo.

Exemplo: Deteção de objetos e inspeção industrial são aplicações de visão computacional.

Relacionados: modelo multimodal · deep learning

Zero-shot

0 menções PTIA · 12 semanas

Execução de uma tarefa através de instruções sem fornecer exemplos específicos no prompt.

Exemplo: Pedir ao modelo que classifique um texto apenas com a descrição das categorias.

Relacionados: prompt · few-shot
