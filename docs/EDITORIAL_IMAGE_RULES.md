# Editorial Image Rules

## Regra geral

A imagem deve explicar a ideia do post, nao decorar o post.

Para PTIA, cada imagem deve ser:

- sobria;
- limpa;
- util;
- sem hype visual;
- sem texto falso legivel;
- sem logos inventados;
- adequada a profissionais e PME portuguesas.

## Logos e marcas

Quando o post for sobre uma empresa especifica, como Anthropic, OpenAI, Google, Microsoft ou Meta, podemos usar um pequeno sinal visual da marca se isso ajudar a contextualizar a fonte.

Regras:

- usar como referencia editorial, nao como endorsement;
- colocar pequeno e integrado no contexto, por exemplo num card, etiqueta ou canto da composicao;
- evitar o logo como elemento dominante;
- nao alterar o logo de forma enganadora;
- nao criar uma imagem que pareca publicidade oficial da marca.

Exemplo para Anthropic/Claude:

> Incluir um pequeno simbolo discreto do Claude/Anthropic no meio dos cards de workflow, como sinal de fonte do tema, mantendo PTIA como publicacao independente.

## Prompt base

```text
Square editorial image for PTIA about [topic]. Clean Portuguese business magazine style. [main scene]. Include a small, discreet [brand] source mark inside one workflow card, not as the main subject and not as an endorsement. No fake readable text. Sober, premium, practical. Off-white background, charcoal details, deep blue accent, small green detail. Avoid sci-fi, neon, cartoon, and stock-photo people.
```
